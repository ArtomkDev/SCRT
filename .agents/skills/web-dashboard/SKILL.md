# Web dashboard

Prefer server components for identity, guild lists, and authorization. Put privileged Discord and Firestore calls behind server-only helpers. Keep pages focused on rendering and route handlers focused on transport. Provide loading, empty, and error states without invented activity data. Use accessible labels and links; introduce client components only for interaction that needs browser state.
